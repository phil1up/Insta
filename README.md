# insta-

Instagram carousel builds for **TCG Healing Station** (`@tcg_h_s`).

## Charizard G LV.X (DP45)

Intake / diagnosis carousel — 10 square slides (1080×1080).

| File | Slide |
|------|--------|
| `slides/01_cover.jpg` | Cover |
| `slides/02_inspection.jpg` | Inspection |
| `slides/03_under_scope.jpg` | Under the scope |
| `slides/04_edge_whitening.jpg` | Edge whitening |
| `slides/05_surface_wear.jpg` | Surface wear |
| `slides/06_corner_damage.jpg` | Corner wear |
| `slides/07_promo_edge.jpg` | Promo edge |
| `slides/08_border_detail.jpg` | Border detail |
| `slides/09_holo_scuffs.jpg` | Holo scuffs |
| `slides/10_cta.jpg` | CTA |

Caption copy: [`instagram_caption.txt`](instagram_caption.txt)

Rebuild script: [`scripts/build_carousel.py`](scripts/build_carousel.py)

## Posting

1. Upload `slides/01_cover.jpg` … `slides/10_cta.jpg` as an Instagram carousel (in order).
2. Paste the caption from `instagram_caption.txt`.

## PR

Carousel delivered via cloud agent for Instagram posting.
